# Mis Gastos

App web para apuntar gastos en segundos desde el móvil: botones de un toque, categorías, gastos fijos mensuales, ingresos y ahorro de cada mes.

**Cómo instalarla en el móvil:** abre el enlace de GitHub Pages del repositorio en Safari (iPhone) o Chrome (Android) y elige *Compartir → Añadir a pantalla de inicio*.

Los datos se guardan solo en el propio móvil. En *Ajustes → Copia de seguridad* puedes descargar una copia y restaurarla.
